# Langchain in Flowcharts

Build AI agents without writing any code — drag out a flowchart, wire up the logic visually, and get a working LangChain agent underneath.

🔗 **Live demo:** https://langchainflowcharts.bolt.host

## What it does

Instead of hand-writing LangChain chains and agent logic in Python, you compose the agent's behavior as a flowchart — nodes for prompts, tools, conditionals, and branches — and the app translates that visual graph into a running agent. Aimed at people who understand *what* they want an agent to do but don't want to write the orchestration code by hand.

## Status

Built and deployed as a Bolt project; the live app is the source of truth. This repository tracks the project on GitHub as a reference point — see the demo link above for the actual product.
